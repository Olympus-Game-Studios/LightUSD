# Olympus-Game-Studios/LightUSD

A fork of [lighttransport/LightUSD](https://github.com/lighttransport/LightUSD) (formerly tinyusdz) used by Hephaestus Engine as `extern/tinyusdz`.

- `main` mirrors upstream. The workflow on this branch fast-forwards it every day.
- `hephaestus/internal-reference-fix` holds the engine's fix for internal references inside referenced layers. The engine pins a commit on it.
